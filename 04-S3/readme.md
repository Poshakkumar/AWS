> Amazon S3 (Simple Storage Service) is a highly durable, scalable, secure, and cost-effective object storage service. It is one of the most widely used AWS services for storing files, backups, logs, images, videos, static websites, and application data.

# 🚀 What is Amazon S3?

Amazon S3 is an **Object Storage Service** that stores data as **Objects** inside **Buckets**.

Unlike traditional file systems, S3 stores data in a flat structure.

Amazon S3 provides:

- 99.999999999% (11 9's) durability
- High availability
- Virtually unlimited storage
- Strong security
- Global accessibility
