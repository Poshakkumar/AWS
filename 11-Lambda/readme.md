# ⚡ AWS Lambda

> AWS Lambda is a serverless compute service that lets you run code without provisioning or managing servers. It automatically scales your applications and charges only for the compute time you use.

# 🚀 What is AWS Lambda?

AWS Lambda is a **Function as a Service (FaaS)** that executes your code in response to events.

You only upload your code, and AWS handles:

- Server provisioning
- Scaling
- Availability
- Maintenance

---

# ❓ Why Lambda?

Without Lambda

- Manage servers
- OS updates
- Capacity planning
- Infrastructure maintenance

With Lambda

- No server management
- Automatic scaling
- Pay only for execution time
- Fast deployment
