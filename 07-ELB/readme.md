# 🚀 What is Elastic Load Balancing?

Elastic Load Balancing (ELB) automatically distributes incoming traffic across multiple healthy targets.

Instead of sending all requests to one server, ELB spreads the traffic evenly.

---

# ❓ Why ELB?

Without ELB

- Single Point of Failure
- Poor Scalability
- Uneven Traffic Distribution

With ELB

- High Availability
- Automatic Traffic Distribution
- Health Monitoring
- Fault Tolerance
- Better Performance
