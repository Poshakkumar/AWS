# 🚀 What is Amazon RDS?

Amazon RDS is a managed service for relational databases.

AWS handles:

- Hardware provisioning
- OS updates
- Database patching
- Automated backups
- Monitoring
- High Availability

You focus on building applications instead of managing database servers.

---

# ❓ Why Amazon RDS?

Amazon RDS provides:

- Managed Databases
- Automatic Backups
- High Availability
- Easy Scaling
- Security
- Monitoring
- Disaster Recovery
