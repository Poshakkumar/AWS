# 🚀 What is AWS?

**Amazon Web Services (AWS)** is the cloud computing platform provided by Amazon.

It offers more than **200 fully featured cloud services** that help businesses build, deploy, secure, and scale applications without managing physical infrastructure.

AWS provides services for:

- Compute
- Storage
- Networking
- Databases
- Security
- Artificial Intelligence
- Machine Learning
- Analytics
- Internet of Things (IoT)
- Containers
- DevOps
- Serverless Computing

AWS follows a **pay-as-you-go** pricing model, allowing customers to pay only for the resources they consume.

---

## Simple Definition

> AWS is Amazon's cloud platform that provides on-demand IT infrastructure and cloud services over the Internet.

| Year | Milestone |
|------|-----------|

| 2004 | Amazon SQS launched |
| 2006 | Amazon EC2 and Amazon S3 launched |

# 🏗 AWS Well-Architected Framework

The AWS Well-Architected Framework helps design secure, reliable, efficient, and cost-effective cloud applications.

It consists of six pillars:

## 🔒 Security
Protect systems, data, and identities.

## ⚙️ Operational Excellence
Continuously improve operations and automate processes.

## 🛡 Reliability
Recover quickly from failures and maintain availability.

## 🚀 Performance Efficiency
Use resources efficiently and scale as demand changes.

## 💰 Cost Optimization
Avoid unnecessary costs and maximize value.

## 🌱 Sustainability
Optimize workloads to reduce environmental impact.
